# Dhamma Echo 0.6.1 — Implementation & Verification Report

## 2026-10-23 engineering continuation

The 0.6.1 working tree extends the 0.6.0 baseline with source changes to the Rust
catalogue/download commands, Svelte application controller, search/teacher/collection
views, player/queue/library and regression tests. This report does **not** classify
every compound acceptance criterion as completely verified.

- **Resolved defects:** global Space/arrow shortcuts no longer override keyboard
  activation of focused buttons and other interactive controls; the Focused
  Listening entry remains visible at compact widths when a media error occurs.
- **Automated checks (macOS Apple Silicon):** `bun run verify` passed, including
  Svelte typecheck, ESLint, tests, web/site/design checks, Rust Clippy/tests and
  Rust release build. `bun run package` passed for 0.6.1.
- **Playwright:** the interaction, teacher/collection, offline-file and 16
  responsive theme/locale scenarios passed on the mock web catalogue. The
  additional Space keyboard activation and MP4 open/Escape lifecycle scenarios passed.
- **Packaging:** `codesign --verify --deep --strict` passed for the ad-hoc
  signed macOS app and `hdiutil verify` passed for the 0.6.1 DMG.
- **Acceptance checkpoint:** `docs/redesign/ACCEPTANCE_RESULTS.json`, generated by
  `node scripts/redesign-acceptance-ledger.mjs`, maps every AC-01–AC-80 item
  to its source, recorded evidence and verification limitations. VERIFIED
  indicates specific recorded checks, not exhaustive proof of compound criteria.
- **Limitations:** live third-party media reliability, native fullscreen,
  cross-platform Windows/Linux checks, visual contrast measurements and
  assistive technology are not fully verified in this session. Neither public
  publication nor notarization was performed.

Previous 0.6.0 release evidence is retained below.
