# Product

<!-- impeccable:product-schema 1 -->

This is scoped context for the FigCraft design proposal. Product facts are inherited from the repository README; no new functionality or commercial claims are introduced.

## Platform

web

Desktop webview in Tauri; minimum window 860×620. This artifact depicts desktop, not mobile.

## Users

People finding and listening to Dhamma teachings during long desktop listening sessions. This audience/use context is inferred from the existing README, not from new user research.

## Product Purpose

Find a teaching, listen, keep a local position and return without creating an account.

## Capabilities and Constraints

Home, catalogue search/filtering, teachers, collections, audio/video, downloads, favorites, history, queue, appearance/language/rate settings and keyboard help. Bundled read-only catalogue; approved Dhamma Download media hosts; local personal state. MP3/MP4 playback; searchable but unplayable WMA/WMV. No telemetry, ads or cloud account.

## Brand Commitments

Dhamma Echo name and existing lotus. The current user explicitly requested a fresh visual rebuild using Lucide icons and the Impeccable skill. Keep exactly one master FigCraft file.

## Evidence on Hand

Repository README, public/logo.svg, retained 27-board core, 21 source-audited state boards, six native design-system boards and catalogue-derived titles. Playback position, download progress, history and saved/queued items in the design are illustrative fixtures, not the user's personal data.

## Accessibility & Inclusion

English and Myanmar, script-aware line height, keyboard focus and compact-window legibility. The static artifact does not establish functional accessibility compliance; those behaviors require implementation testing.
