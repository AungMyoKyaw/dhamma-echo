# Natural Title Sorting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sort numbered audio titles naturally within each teacher for ASCII and Burmese numerals while preserving stable database pagination.

**Architecture:** Add a total Rust comparator for title strings and register it as a custom SQLite collation on every catalogue connection. Apply that collation in the existing audio-search `ORDER BY`, leaving teacher grouping and the media-ID tie-breaker intact.

**Tech Stack:** Rust 2024, rusqlite 0.40, SQLite, Cargo tests

---

- [ ] **Step 3: Implement the minimal total comparator**

In `src-tauri/src/db.rs`, import `std::cmp::Ordering`. Add helpers that:

```rust
fn decimal_digit(character: char) -> Option<u8> {
    match character {
        '0'..='9' => Some(character as u8 - b'0'),
        '၀'..='၉' => Some((character as u32 - '၀' as u32) as u8),
        _ => None,
    }
}

fn leading_number(value: &str) -> Option<Vec<u8>> {
    let digits: Vec<u8> = value
        .trim_start()
        .chars()
        .map_while(decimal_digit)
        .collect();
    (!digits.is_empty()).then_some(digits)
}

fn compare_digit_runs(left: &[u8], right: &[u8]) -> Ordering {
    let left = left.iter().skip_while(|digit| **digit == 0).copied().collect::<Vec<_>>();
    let right = right.iter().skip_while(|digit| **digit == 0).copied().collect::<Vec<_>>();
    left.len().cmp(&right.len()).then_with(|| left.cmp(&right))
}

fn natural_title_order(left: &str, right: &str) -> Ordering {
    let lexical = || left.to_lowercase().cmp(&right.to_lowercase());
    match (leading_number(left), leading_number(right)) {
        (Some(left_number), Some(right_number)) => {
            compare_digit_runs(&left_number, &right_number).then_with(lexical)
        }
        (Some(_), None) => Ordering::Less,
        (None, Some(_)) => Ordering::Greater,
        (None, None) => lexical(),
    }
}
```

Keep the implementation private to the database module.

const NATURAL_TITLE_COLLATION: &str = "NATURAL_TITLE";
